# ZMK本体はE24-GHのforkを使っています

`config/west.yml` は、ZMK本体を本家 `zmkfirmware/zmk` ではなく
**E24-GHのfork** から取得するようになっています。

```yaml
- name: zmk
  remote: e24-gh
  revision: v0.3-zen
```

| | |
| --- | --- |
| fork | https://github.com/E24-GH/zmk |
| ブランチ | `v0.3-zen` |
| ベース | 本家の `v0.3` タグ |
| 差分 | **コミット1つだけ** |

ベースは本家のv0.3そのもので、差分は下記の1件のみです。
中身は fork のコミット (`fix(split): retry peripheral advertising when it
fails to start`) で確認できます。

## 何を直しているか

分割キーボードの左手(peripheral)が、長時間放置したあと無反応のまま
戻らなくなることがある問題への対策です。

左手は右手との接続が切れると、すぐに再接続用の電波を出し直します。
しかしZMK v0.3では、切れた直後はまだ前の接続の後始末が終わっておらず、
電波の送信開始に失敗することがあります。
**失敗しても再試行する仕組みが無いため、そのまま黙り込みます。**

こうなると、

- 左手のキーがまったく効かない
- 右手は普通に使える
- 何時間待っても復帰しない
- 電池を入れ替えても直らない
- **電源スイッチを入れ直すと直る**

という状態になります。修正は「失敗したら1秒後にやり直す」というものです。

## forkをやめる場合

本家ZMKを使いたい場合は、`config/west.yml` を次のように戻せます。
上記の問題が再発する可能性がありますが、ビルド自体は通ります。

```yaml
- name: zmk
  remote: zmkfirmware
  revision: v0.3
```
